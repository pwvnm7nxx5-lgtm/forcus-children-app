# 「計算問題作成」PDF説明書 制作設計図

## 1. 制作方針

- 対象: 「計算問題作成」を初めて使う教員・支援員
- 目的: 説明を読んだ人が、5分以内に問題を設定し、プレビューを確認して、印刷またはPDF保存できること
- 形式: A4縦、全8ページ、フルカラーPDF
- 制作モデル: Lunaを推奨する
- Solの使いどころ: 完成PDFの内容照合、文字切れ、画像の誤注釈、印刷崩れの最終確認のみ
- 編集元: A4縦サイズのPowerPointを推奨する。PDFと編集用PPTXを両方残す

Lunaは、下記のページ構成、画面キャプチャー指示、掲載文、検品条件を変更せずに制作する。画面に存在しない機能や操作は追加しない。

## 2. 読者が最初に理解すること

説明書の冒頭で、次の3点を明確にする。

1. 左側で設定し、右側のプレビューで結果を確認する。
2. 設定を変えると、基本的にすぐプレビューへ反映される。
3. 最後に「印刷 / PDF保存」を押す。

初見の人へ一度に全機能を説明しない。1枚作るために必要な設定と、必要な人だけ使う詳細設定を分ける。

## 3. 表現とデザイン

### 基本デザイン

- 背景: 白
- 本文: 濃いグレーまたは黒
- 主色: アプリの青緑系
- 補助色: 青、緑、黄、赤を役割別に限定して使う
- 青: 問題内容の設定
- 緑: 用紙・印刷の設定
- 黄: 任意の補助機能
- 赤: 個人情報、印刷設定、更新時の注意
- 本文フォント: BIZ UDPゴシック、Noto Sans JP、またはYu Gothic
- 本文サイズ: 10.5pt以上
- 見出しサイズ: 18pt以上
- ページタイトル: 24pt前後
- 画面内の文字を説明文で再現するときは、実際のUI表記と完全に一致させる

### 視覚ルール

- スクリーンショットを主役にする。文章だけのページを作らない
- 操作順は、青い丸数字と太い矢印で示す
- 1つのスクリーンショットに付ける吹き出しは最大6個
- 画面キャプチャーに青い選択枠、ブラウザーコメント、マウスカーソルを残さない
- スクリーンショットを変形しない。縦横比を保つ
- 小さいUI部分は、全体画面とは別に拡大した切り抜きを併記する
- イラストは装飾に使わず、操作の流れ、表示方法の比較、印刷の分岐を説明するインフォグラフィックに使う

## 4. 画面キャプチャー仕様

### 共通条件

- 最新の公開版または最新のmainを使う
- 画面幅は1440px前後、高さは1000px前後
- ブラウザー倍率は100%
- 名前と日付は空欄にする
- プリント名は「計算問題作成」のままにする
- 答えページを表示する場合も、児童名などの個人情報を入れない
- キャプチャー前に、プレビューの先頭ページが見える位置まで戻す

### 必要なキャプチャー

| ID | 内容 | 設定 | 用途 |
|---|---|---|---|
| S01 | アプリ全体 | たし算、2桁と1桁、筆算、12問、縦向き、2列 | 表紙、画面全体の案内 |
| S02 | 左側設定欄の上部 | S01と同じ | 計算、桁数、表示の説明 |
| S03 | 左側設定欄の下部 | S01と同じ | 用紙、列数、大きさ、枚数、各チェックの説明 |
| S04 | 横式のプレビュー | たし算、2桁と1桁、横式、12問 | 表示方法の比較 |
| S05 | 横式＋計算スペース | S04と同じ計算条件 | 表示方法の比較 |
| S06 | 筆算のプレビュー | S04と同じ計算条件 | 表示方法の比較 |
| S07 | 小数用の設定欄 | 小数のたし算、横式＋計算スペース | 小数の桁数と補助表示の説明 |
| S08 | 小数の問題と計算スペース | 整数部分1桁、小数第2位まで、8問 | 小数点チェックの説明 |
| S09 | かけ算15問 | 2桁×3桁、筆算、15問、横向き、4列 | 多い問題数の自動調整例 |
| S10 | 問題ページと答えページ | 答えページON | 答えページの説明 |
| S11 | ブラウザーの印刷画面 | A4、アプリと同じ向き | 印刷とPDF保存の説明 |

S11はOSやブラウザーによって表示が変わる。実画面を使えない場合は、特定のブラウザーに見える偽画面を作らず、「印刷先」「用紙サイズ」「倍率」の3項目だけを示す簡単な図解に置き換える。

## 5. ページ構成

### 1ページ目: 表紙と60秒概要

**ページタイトル**

> 計算問題作成 かんたん使い方ガイド

**サブタイトル**

> 計算の種類・桁数・表示方法を選んで、必要なプリントをすぐ作れます。

**掲載要素**

- S01を大きく配置する
- 「設定」「プレビュー」「印刷」の3地点へ番号を付ける
- 下部に3ステップのインフォグラフィックを置く

**3ステップの文言**

1. 計算と桁数を選ぶ
2. プレビューを確認する
3. 印刷またはPDF保存する

**小さな案内**

> まずは2・3ページだけ見れば、基本のプリントを作れます。

### 2ページ目: 画面の見方

**ページタイトル**

> 画面は「設定」と「プレビュー」に分かれています

**レイアウト**

- 左半分: S01の設定欄を拡大
- 右半分: S01のプレビューを拡大
- 中央に左から右へ向かう矢印を置く

**吹き出し**

1. 「左側で問題の内容を決めます」
2. 「右側に完成イメージが表示されます」
3. 「設定を変えると、すぐプレビューに反映されます」
4. 「もんだいページと、こたえページを確認できます」

**注意書き**

> 「問題の大きさ上限」は最大サイズです。問題数が多い場合は、A4に収まるよう自動で小さくなります。

### 3ページ目: まず1枚作る

**ページタイトル**

> 6つの手順で作ってみましょう

**例に使う設定**

- 計算: たし算
- 1つ目の桁数: 2桁
- 2つ目の桁数: 1桁
- 表示: 筆算
- 問題数: 12
- 用紙の向き: 縦向き
- 列数: 2

**操作手順**

1. 「計算」で「たし算」を選ぶ
2. 「1つ目の桁数」と「2つ目の桁数」を選ぶ
3. 「表示」で「筆算」を選ぶ
4. 問題数、用紙の向き、列数を決める
5. 右側のプレビューを確認する
6. 「印刷 / PDF保存」を押す

**補足ボックス**

> 別の問題に変えたいときは「作り直す」を押します。設定はそのままで、数字だけが変わります。

### 4ページ目: 計算と数の大きさを決める

**ページタイトル**

> 作りたい計算と、2つの数の大きさを選びます

**掲載する計算一覧**

- たし算
- ひき算
- かけ算
- わり算（あまりなし）
- 小数のたし算
- 小数のひき算
- 小数のかけ算
- 小数 ÷ 整数
- 整数 ÷ 小数
- 小数 ÷ 小数

**整数の説明文**

> 「1つ目」と「2つ目」は、式の左右に使う2つの数です。それぞれ1桁から5桁まで選べます。

**小数の説明文**

> 小数を選ぶと、整数部分の桁数と、「小数第1位まで」「小数第2位まで」「小数第3位まで」から使う位を、それぞれの数について選べます。「0（1未満）」を選ぶと、0.4や0.38のような数を作れます。

**小数用の図解**

- S07の「1つ目の整数部分の桁数」「1つ目の小数」を青枠で1組にする
- S07の「2つ目の整数部分の桁数」「2つ目の小数」を緑枠で1組にする
- 例として「整数部分1桁＋小数第2位まで → 7.25」を示す
- 例として「0（1未満）＋小数第1位まで → 0.6」を示す

**注意書き**

> 選んだ計算で使わない設定は、薄い色になって操作できないことがあります。故障ではありません。

### 5ページ目: 3つの表示方法

**ページタイトル**

> 学習の目的に合わせて表示を選びます

同じ計算条件を使ったS04、S05、S06を横並びにする。

| 表示 | 向いている使い方 | 説明 |
|---|---|---|
| 横式 | 暗算、式を見て答える練習 | 式と答え欄をすっきり表示します |
| 横式＋計算スペース | 式を見て、自分で筆算を書く練習 | 式の下に必要な大きさの計算マスを表示します |
| 筆算 | 桁をそろえて計算する練習 | 数字をマスに入れた筆算を表示します |

**選び方の小さなフロー図**

- 式だけで解く → 横式
- 自分で筆算を書きたい → 横式＋計算スペース
- 最初から桁をそろえて見せたい → 筆算

**補助機能の説明**

- 「繰り上がり・繰り下がりのマスをつける」は、対応する筆算でだけ使える
- 「計算スペースに記号を表示する」は、横式＋計算スペースでだけ使える
- かけ算の問題数が多いときは、A4に収まる列数と大きさへ自動調整される

### 6ページ目: 小数点の表示と答えページ

**ページタイトル**

> 小数点の補助表示と、答えページを調整できます

**小数点の説明**

S08を使い、横に書かれた問題と、その下の計算スペースを分けて示す。

> 「計算スペースに小数点をつける」は、下の計算マスにある補助用の小数点だけを表示・非表示にします。横に書かれた問題の小数点は消えません。

> 「解答欄に小数点をつける」は、問題ページの解答欄に補助用の小数点を表示するか選びます。答えページでは正しい小数点を必ず表示します。

**答えページの説明**

- S10で「もんだい」と「こたえ」を並べる
- 「答えページをつける」がONなら、各問題プリントに対応する答えページを作る
- OFFなら、問題ページだけを印刷する

**複数枚の説明**

> 「作成する枚数」を2以上にすると、同じ設定で別の問題プリントを作ります。単純なコピーではなく、数字の違う問題になります。

### 7ページ目: 用紙調整、印刷、PDF保存、共有

**ページタイトル**

> 仕上げて、印刷または保存します

**用紙設定の説明**

- 用紙の向き: 縦向き / 横向き
- 穴あけガイド: なし / 左の真ん中 ◀ / 上の真ん中 ▲
- 列数: 1列あたりの横幅と、縦に並ぶ問題数を調整する
- 問題の大きさ上限（%）: 問題を大きくしすぎないための上限
- 作成する枚数: 異なる問題プリントを何枚作るか

**印刷の手順**

1. プレビューで、問題がA4内に収まっているか確認する
2. 「印刷 / PDF保存」を押す
3. 印刷画面で用紙サイズがA4になっているか確認する
4. プリンターへ出す場合はプリンターを選ぶ
5. PDFにする場合は「PDFに保存」を選ぶ

**印刷設定の注意**

> アプリ側でA4に合わせています。印刷画面では用紙サイズをA4にし、倍率は100%または既定のままにします。別の「用紙に合わせる」を重ねて使うと、意図せず小さくなることがあります。

**共有URLの説明**

> 「共有URLをコピー」を押すと、現在の設定と問題を同じ状態で開けるURLをコピーできます。

**個人情報の注意**

> 共有URLには、入力した名前、日付、プリント名、問題内容が含まれます。共有前に、児童の名前など不要な個人情報を消してください。

### 8ページ目: 困ったとき

**ページタイトル**

> 困ったときの確認ポイント

| 状況 | 確認すること |
|---|---|
| 設定が選べない | その計算や表示方法では使わない項目は、自動で操作不可になります |
| 問題を別の数字にしたい | 「作り直す」を押します |
| 問題が小さく見える | 問題数を減らす、列数を見直す、用紙を横向きにする、問題の大きさ上限を上げる、の順で確認します |
| 印刷がA4にならない | 印刷画面の用紙サイズがA4か、アプリと印刷画面の向きが同じか確認します |
| 古い画面のまま変わらない | WindowsではCtrl+F5またはCtrl+Shift+Rで再読み込みします。URLやブックマークは変わりません |
| 共有URLをコピーできない | URL欄の末尾に共有データが追加されるので、アドレス欄のURL全体をコピーします |
| 印刷開始まで時間がかかる | 印刷画面がすぐ出る場合、その後の待ち時間はプリンターや印刷待ち行列の可能性があります。いったんPDF保存して印刷する方法も確認します |

**最後のチェックリスト**

- 計算の種類は合っている
- 2つの数の桁数は合っている
- 表示方法は合っている
- 問題数と列数は合っている
- 答えページのON/OFFは合っている
- 名前などの個人情報を確認した
- A4の向きを確認した

## 6. インフォグラフィック指示

### 操作フロー

「計算を選ぶ」→「数の大きさを決める」→「表示を選ぶ」→「用紙を整える」→「印刷」の5ブロックで作る。各ブロックには、実際のUIの小さな切り抜きを1つだけ置く。

### 表示方法の比較

同じ式を3つの表示方法で並べる。式や答えが異なる画像を使うと比較しにくいため、可能なら同じ問題セットを共有URLで保持してから表示だけ切り替えて撮影する。

### 小数の設定図

次の対応を線で結ぶ。

- 1つ目の整数部分の桁数 + 1つ目の小数 → 1つ目の数
- 2つ目の整数部分の桁数 + 2つ目の小数 → 2つ目の数

小数点を消すチェックではなく、計算スペースの補助表示を切り替えるチェックであることを、問題の式と計算マスの2層で示す。

## 7. Lunaへの制作指示

### 納品物

1. `計算問題作成_使い方ガイド.pdf`
2. `計算問題作成_使い方ガイド_編集用.pptx`
3. 使用したスクリーンショット一式
4. 画像の出典・作成方法を記載した短いメモ

### PDF仕様

- A4縦、8ページ
- すべてのフォントを埋め込む
- ページ番号を2ページ目以降の右下に入れる
- リンクを掲載する場合はクリック可能にする
- 画像解像度は印刷時150dpi以上、可能なら200dpi以上
- ファイルサイズは目安として10MB以内
- PDFを画像へ書き出し、文字切れ、画像のぼけ、余白、ページ抜けを目視確認する

### 禁止事項

- 存在しないボタン、チェック、設定を追加しない
- UIの名称を言い換えない
- スクリーンショット内の数字や文字を画像編集で書き換えない
- ローカルホストのURLを利用者向け本文へ掲載しない
- 実在する児童名や個人情報を使わない
- 装飾だけのイラストで操作画面を小さくしない
- 文字を画像の上に重ねて、UIが読めなくなる配置をしない

## 8. 完成前の検品

### 内容

- 計算の選択肢10種類が実画面と一致している
- 小数の整数部分は「0（1未満）」を選べると説明している
- 小数部分は第1位から第3位まで選べると説明している
- 横式、横式＋計算スペース、筆算の違いが比較できる
- 小数点チェックが、横に書かれた問題の小数点を消す機能として説明されていない
- 答えページでは正しい小数点を必ず表示すると説明している
- かけ算15問の例がA4内に収まっている
- 共有URLの個人情報注意がある
- Ctrl+F5後もURLやブックマークは変わらないと説明している

### 見た目

- A4を100%表示したときに本文が読める
- 画面キャプチャーのUI文字が判読できる
- 吹き出しの矢印が、別の設定を指していない
- 同じ色が複数の意味に使われていない
- 画像と本文の対応がページをまたがない
- ページ下部に文字切れがない

### 印刷

- A4縦で8ページになる
- 余計な白紙がない
- 罫線、番号、アイコンが欠けない
- 白黒印刷でも見出しと注意が判別できる

## 10. 推奨する制作分担

- Codex: 実画面と仕様の整理、設計図の更新
- Luna: スクリーンショット取得、図解、PPTX制作、PDF書き出し
- Sol: 完成PDFと実画面の照合、誤表記とレイアウト崩れの最終監査

Lunaだけでも制作可能である。Solを使う場合は、制作を重複させず、完成後の監査に限定する。
