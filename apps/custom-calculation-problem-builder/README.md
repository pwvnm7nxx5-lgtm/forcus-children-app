# 計算問題作成

学年にかかわらず、四則計算・小数計算と2つの数の桁数を指定して、計算プリントを作る静的Webアプリです。

## できること

- たし算、ひき算、かけ算、わり算（あまりなし）、わり算（あまりあり）を選択
- 小数のたし算・ひき算・かけ算、小数÷整数、整数÷小数、小数÷小数を選択
- 1つ目と2つ目の数を、それぞれ1〜5桁で指定
- ひき算は答えが負にならないように、大きい数・小さい数の桁数を選択
- わり算は、割られる数・割る数の桁数を選択。あまりありでは、商1以上・0より大きく割る数未満の余りになる問題だけを作成
- 横式・筆算、繰り上がり・繰り下がり、補助マス、問題数、列数、答えページ、複数枚、共有URL、印刷に対応
- 保存・呼び出し、設定保存、問題ごとの保存、JSONバックアップに対応

小数を選んだ場合、桁数は小数点より左の整数部分の桁数です。小数はすべて小数第1位までの問題を作成します。

筆算では、同じページ内で必要な最大のマス数にそろえて表示します。かけ算とわり算の筆算は、A4に収まる問題数へ自動調整します。あまりありの解答は、横式で「商 あまり 余り」、筆算で商・途中計算・最後の余りを表示します。

保存したプリントは、このブラウザ内の計算問題作成アプリに保存されます。別の環境へ移す場合は、保存一覧からJSONバックアップを書き出して読み込みます。名前と日付は保存されません。

## 多枚数のプレビュー性能

行の高さは「全ページの制約解除→全ページの測定→結果反映」の順でまとめて処理します。用紙自動フィット中はプレビューのズームを固定し、同一フレーム内の横式調整要求はまとめます。問題・答えの生成枚数や、印刷前のフィットは省略しません。

2026-09-28の同一Chrome環境で、30枚＋答え30枚の変更完了までを計測すると、横式は約2.43秒→1.15秒、筆算は約13.15秒→6.92秒でした。端末・問題形式で時間は変わり、大量の筆算は引き続き数秒かかります。

専用の `playwright-cli` セッションで本アプリを開き、答えを表示した状態で `run-code --filename scripts/measure-calculation-print-performance.js` を実行すると、1・10・30枚の完了時間とレイアウト計算回数を確認できます。テストは `node --test apps/shared/tests/print-performance.test.js`、印刷の回帰確認は `node scripts/verify-paper-autofit.js` を使用します。検証用ブラウザは終了後に閉じます。
