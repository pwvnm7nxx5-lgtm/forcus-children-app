# 計算問題作成

学年にかかわらず、四則計算・小数計算と2つの数の桁数を指定して、計算プリントを作る静的Webアプリです。

## できること

- たし算、ひき算、かけ算、わり算（あまりなし）を選択
- 小数のたし算・ひき算・かけ算、小数÷整数、整数÷小数、小数÷小数を選択
- 1つ目と2つ目の数を、それぞれ1〜5桁で指定
- ひき算は答えが負にならないように、大きい数・小さい数の桁数を選択
- わり算は、割られる数・割る数の桁数を選択
- 横式・筆算、繰り上がり・繰り下がり、補助マス、問題数、列数、答えページ、複数枚、共有URL、印刷に対応
- 保存・呼び出し、設定保存、問題ごとの保存、JSONバックアップに対応

小数を選んだ場合、桁数は小数点より左の整数部分の桁数です。小数はすべて小数第1位までの問題を作成します。

筆算では、同じページ内で必要な最大のマス数にそろえて表示します。かけ算とわり算の筆算は、A4に収まる問題数へ自動調整します。

保存したプリントは、このブラウザ内の計算問題作成アプリに保存されます。別の環境へ移す場合は、保存一覧からJSONバックアップを書き出して読み込みます。名前と日付は保存されません。
