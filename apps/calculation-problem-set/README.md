# 計算問題集

1〜5年生の計算練習を、ひとつの画面で設定して印刷する静的Webアプリです。3〜5年生では、その学年で学ぶ小数計算も選べます。3・4年生のわり算では、あまりなし／あまりありと、あまりなし専用の「九九の範囲」を選べます。

## 対応内容

- 1年生: たし算、ひき算、たし算・ひき算ミックス
- 2年生: たし算、ひき算、たし算・ひき算ミックス、九九
- 3・4年生: わり算（あまりなし）、わり算（あまりあり）
- 桁数、繰り上がり・繰り下がり、横式・筆算、問題数、列数
- A4自動調整、縦向き・横向き、答えページ、穴あけガイド、共有URL

「九九の範囲」は、除数と商がともに1〜9の整数で、被除数がその積になる問題です。桁数欄はこの難易度では表示しません。

既存の学年別計算プリントは残したまま、このアプリでは計算方法からプリントを探せます。
