# 点つなぎ作成

左のお手本の線を、右の同じ正方格子へ写すA4縦の印刷教材。数字順に点を結ぶ教材ではありません。入口の「教材」カテゴリ・全学年表示から開けます。入口では「利用可」と表示します。

## 使い方

1. 点の数・線の本数・レベル・一筆書き・全ての点を繋げる・問題数を変えると、自動で問題を作り直します。数値の手入力は最後の入力から約300ms後、入力確定や選択式の設定はすぐに反映します。手動のお手本がある場合は自動で上書きせず、「全問を作り直す」で確認してから反映します。「条件を元に戻す」で形を残して設定変更を取り消せます。
2. ヒント4種類、1ページ1・2・4問、穴あけガイド（なし・左の真ん中・上の真ん中）を選ぶ。これらの変更では形は変わりません。
3. 各問の「この問題を作り直す」でその1問だけ変更できます。他の問題は残ります。
4. 「印刷 / PDF保存」またはCtrl+P。A4縦を選んでください。印刷倍率や余白が変わっても、ページ全体を印刷領域に合わせて同じ比率で縮尺調整します。入力途中・作成中・生成できない条件では前の問題を残し、アプリの印刷ボタンを無効にします。Ctrl+Pはブラウザ標準のままなので、その場合は変更前のプレビューを印刷します。

作成済み問題と表示設定は、この端末のブラウザに保存します。再読み込みや入口へ戻っても同じ問題を開けます。外部へ送信しません。保存を使えない環境でもその場で作成・印刷できます。

## 手動でお手本を作る

1. 各問題の「手動で作る・編集」を押します。今のお手本を修正でき、「全消去」で白紙からも作れます。
2. 点を2つ選ぶと線が引けます。続けて次の点を選ぶと線が繋がります。同じ線の両端をもう一度選ぶと消せます。「点の選択を解除」で別の場所から描き始められます。
3. 「ひとつ戻す」は線の追加・削除・全消去を取り消します。「このお手本を保存」でその1問だけ確定し、「キャンセル」やEscでは元のお手本を変えません。

スマホのタップ、または矢印キーとEnter/Spaceでも操作できます。手動の線の本数は実際に描いた数（1〜60本）で、自動作成用の本数は変更しません。点の数・線のレベル・一筆書き・ひとまとまりの設定には従い、交差・重複・範囲外の向きや長さの線は引けません。長い直線は間の点を順に選びます。レベル2/3で追加された方向も1本以上必要です。編集中は一時的に離れた形などを作れますが、条件を満たすまで保存できません。分岐・閉路を作る場合は設定欄の一筆書きをOFFにします。

手動と自動のお手本は同じプリントに混ぜられます。ヒントと始点は保存した線から作り、印刷時も形を変えません。ページ下部の線の本数は、そのページの実際の本数または範囲を表示します。編集中にCtrl+Pで印刷した場合は、未保存の下書きではなく保存済みのお手本を印刷し、編集画面は印刷しません。保存済みの手動問題を自動作成へ置き換える際は確認を出します。

静的HTML/CSS/JavaScriptで、ビルドや外部ライブラリは不要です。公開サイト・ローカルHTTPではWorkerを使って画面を止めずに生成します。HTMLを直接開く場合は、上限付き探索の間に画面更新を挟んで生成します。

## 設定・構造

初期値と範囲は `generator.js` の `DEFAULTS` / `LIMITS` に集約しています。初期値は縦5×横5、線5本、レベル1、一筆書きON、全ての点を繋げるON、ヒントなし、4問、1ページ4問。点の数は各方向1〜12、線は1〜60区間、問題数は1〜60です。1点だけ、必要な斜め線を置けない格子、点数を超える一筆書きなどは理由を表示します。条件は自動変更しません。

「全ての点を繋げる」は、線に使う点がひとまとまりに繋がる設定です。格子の全点を使う意味ではなく、線の本数も増やしません。一筆書きをOFFにしても、分岐や閉じた形を含む1つの図形になります。両方OFFなら離れた図形も作れます。一筆書きONでは、この設定にかかわらず一本道になります。旧版の保存問題は、既にひとまとまりなら形を保持し、離れていれば初期ONの条件で自動作り直しします。題名・名前・ヒント・穴あけ設定は保持します。

「スタートを大きくする」の下に「ゴールを大きくする」（初期OFF）があります。スタートは輪（○）、ゴールは四角（□）で点を囲み、点自体も大きくして白黒で区別します。両側の同じ点に表示し、各描画順の先頭・末尾を参照します。一筆書きOFFでは各まとまりの終点を表示し、閉路では同じ点に○と□を重ねます。自動・手動どちらも同じ仕組みです。切替・保存・印刷で問題の形は変えず、古い保存データにゴール設定がない場合はOFFにします。

- `generator.js`：許可方向、交差・重複判定、生成、描画順、問題検証。レベル2/3の追加方向を必ず使います。一筆書きONは点の再訪のない開いた道。OFFは分岐・閉路も可能です。`connectAll` がONなら既存の図形に接続する線だけを追加し、検証でも全使用点の連結を確認します。OFFなら従来どおり離れた形も可能です。旧版との互換性のため、エンジン呼び出しで同項目が省略された場合はOFFとして扱います。
- `worker.js`：条件を満たす問題を別スレッドで生成。最大40試行・24,000探索ノード・1問350msで終了し、見つからなければ理由を返します。
- `app.js`：条件の自動反映と作成済み問題の保持を管理。連続変更では古い作成処理を中止して最後の条件を反映し、空欄や生成不能な条件では前の問題を保ちます。両側のSVGは同じ座標・寸法で描画。OFFの描画順は全線を1回ずつ描く複数のまとまりを保持し、それぞれの始点を輪で表示できます。唯一の筆順は強制しません。
- `manual-model.js`：手動の線追加・削除、保存時の共通条件検証、実線数と描画順の確定。`manual: true` の問題だけ実線数を使い、自動問題の指定本数チェックは維持します。保存キーを変えず、旧版の問題と手動問題を共存させます。
- `manual-editor.js`：拡大した点の編集ダイアログ。下書きと確定済み問題を分離し、取り消し履歴・タップ・キーボード・フォーカスを管理します。
- `styles.css`：既存の `grade1-common.css` を使った設定欄とプレビュー。点の間隔は縦横同一、左右の倍率も同一。7mm未満なら配置数を減らす案内を出します。

共通の印刷補助スクリプトは算数向けの「答え・枚数・列数・拡大率・向き」を追加するため、この教材には読み込みません。左設定・右プレビュー、同じ `#pages` DOM、`window.print()`、A4 CSS、穴あけガイドの表示規約は既存教材にそろえています。印刷では共通補助と同じく、A4論理ページ全体を物理的な印刷領域に合わせる構成を使い、下部の条件表示だけが次ページへ押し出されるのを防ぎます。既存の共通スクリプトと既存アプリ本体は変更していません。
