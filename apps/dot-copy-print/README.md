# 点つなぎ作成

左のお手本の線を、右の同じ正方格子へ写すA4縦の印刷教材。数字順に点を結ぶ教材ではありません。入口の「教材」カテゴリ・全学年表示から開けます。入口では「利用可」と表示します。

## 使い方

1. 点の数・線の本数・レベル・一筆書き・問題数を変えると、自動で問題を作り直します。数値の手入力は最後の入力から約300ms後、入力確定や選択式の設定はすぐに反映します。「全問を作り直す」は同じ条件で別の問題を作りたいときに使います。
2. ヒント3種類、1ページ1・2・4問、穴あけガイド（なし・左の真ん中・上の真ん中）を選ぶ。これらの変更では形は変わりません。
3. 各問の「この問題を作り直す」でその1問だけ変更できます。他の問題は残ります。
4. 「印刷 / PDF保存」またはCtrl+P。A4縦を選んでください。印刷倍率や余白が変わっても、ページ全体を印刷領域に合わせて同じ比率で縮尺調整します。入力途中・作成中・生成できない条件では前の問題を残し、アプリの印刷ボタンを無効にします。Ctrl+Pはブラウザ標準のままなので、その場合は変更前のプレビューを印刷します。

作成済み問題と表示設定は、この端末のブラウザに保存します。再読み込みや入口へ戻っても同じ問題を開けます。外部へ送信しません。保存を使えない環境でもその場で作成・印刷できます。

静的HTML/CSS/JavaScriptで、ビルドや外部ライブラリは不要です。公開サイト・ローカルHTTPではWorkerを使って画面を止めずに生成します。HTMLを直接開く場合は、上限付き探索の間に画面更新を挟んで生成します。

## 設定・構造

初期値と範囲は `generator.js` の `DEFAULTS` / `LIMITS` に集約しています。初期値は縦5×横5、線5本、レベル1、一筆書きON、ヒントなし、4問、1ページ4問。点の数は各方向1〜12、線は1〜60区間、問題数は1〜60です。1点だけ、必要な斜め線を置けない格子、点数を超える一筆書きなどは理由を表示します。条件は自動変更しません。

- `generator.js`：許可方向、交差・重複判定、生成、描画順、問題検証。レベル2/3の追加方向を必ず使います。一筆書きONは点の再訪のない開いた道。OFFは分岐・閉路・離れた形も可能です。
- `worker.js`：条件を満たす問題を別スレッドで生成。最大40試行・24,000探索ノード・1問350msで終了し、見つからなければ理由を返します。
- `app.js`：条件の自動反映と作成済み問題の保持を管理。連続変更では古い作成処理を中止して最後の条件を反映し、空欄や生成不能な条件では前の問題を保ちます。両側のSVGは同じ座標・寸法で描画。OFFの描画順は全線を1回ずつ描く複数のまとまりを保持し、それぞれの始点を輪で表示できます。唯一の筆順は強制しません。
- `styles.css`：既存の `grade1-common.css` を使った設定欄とプレビュー。点の間隔は縦横同一、左右の倍率も同一。7mm未満なら配置数を減らす案内を出します。

共通の印刷補助スクリプトは算数向けの「答え・枚数・列数・拡大率・向き」を追加するため、この教材には読み込みません。左設定・右プレビュー、同じ `#pages` DOM、`window.print()`、A4 CSS、穴あけガイドの表示規約は既存教材にそろえています。印刷では共通補助と同じく、A4論理ページ全体を物理的な印刷領域に合わせる構成を使い、下部の条件表示だけが次ページへ押し出されるのを防ぎます。既存の共通スクリプトと既存アプリ本体は変更していません。

## 検証

```powershell
node --test apps/dot-copy-print/tests/generator.test.js apps/shared/tests/print-performance.test.js apps/clock-print-grade1/tests/*.test.js
python -m http.server 4190 --bind 127.0.0.1
```

別ターミナルで隔離したブラウザを起動します。CLIの `run-code --filename` 用スクリプトです。

```powershell
npx --yes --package @playwright/cli playwright-cli -s=dot-qa open http://127.0.0.1:4190/apps/dot-copy-print/ --browser chrome --headed
npx --yes --package @playwright/cli playwright-cli -s=dot-qa run-code --filename scripts/verify-dot-copy-print.js
npx --yes --package @playwright/cli playwright-cli -s=dot-qa close
```

Edgeは `--browser msedge`。実際の印刷ダイアログは `node scripts/verify-dot-native-preview.js chrome` または `edge` で確認します。このスクリプトは4190のサーバーと、インストール済みのブラウザを使用し、自分で起動したテスト用ブラウザだけを閉じます。

2026-10-15の確認結果：

- 生成・既存時計・共通印刷の単体テスト21件合格。生成480パターン、OFFの形の多様性100パターン、境界条件、独立した交差判定との全候補比較を含みます。
- Chrome / Edgeでヒント8通り、始点と描画順、個別作り直し、条件の自動反映、生成失敗時の保持、再読み込み、モバイル表示、入口往復を確認。
- 両ブラウザでA4の1・2・4問配置と穴あけ3設定の計12 PDF、画面と印刷の寸法一致・問題途中の改ページなし・白紙増加なしを確認。
- Chrome / Edgeの実際のA4印刷プレビューを開いて確認。既存の計算問題作成・計算問題集の複数枚と答えON/OFF、漢字2枚の計5 PDFも合格。
- Workerなしの予備経路で新規生成・個別作り直し、長い教材名と名前の印刷も確認。PDFの用紙寸法、各問の連続した番号、白紙なし、線の用紙内配置は `python scripts/measure-dot-copy-pdfs.py` で検査します。
- 条件6項目の自動反映、数値の連続入力の集約、空欄の保持、作成中に変更した最新条件の優先を確認。
- 写真で報告された縦3×横3点・線2本・4問は、修正前に110％印刷で条件表示だけが2枚目へ出ることを再現。修正後は `scripts/verify-dot-print-pages.js` で両ブラウザの90・100・110・125％、余白あり、拡大＋余白あり、4問・8問の計24 PDFを検証し、全問題・全点・各ページの条件表示が残ることを確認。
- 実機プリンターでの紙出力は未確認。探索上限により、数学的には可能な条件でも作成できない場合があります。その場合は下位レベルへ変更せず、同条件での再試行などを案内します。

確認用の画像・PDFは `output/playwright/` にあり、アプリの公開対象には含めません。
