# 絵とことばのマッチング作成

上段の絵と下段のことばを点から点へ線で結ぶ印刷教材です。ブラウザで描く機能はありません。

## 絵とことばの選び方

身近な題材240種類を採用しています。動物48種類・食べ物60種類・生活用品60種類・学校の道具24種類・乗り物と街24種類・自然12種類・遊び12種類です。旧版の絵文字素材や魔法の道具は出題しません。

白背景に実物の形が伝わるカラーイラストを画像生成で制作しています。生成した絵と日本語の名前を全件目視で照合しています。児童による認識の確認は未実施です。学習段階に合わせて語彙一覧で絵を確認し、必要なものを選んでください。

絵は20枚の素材にまとめてローカルに同梱しています。表示用WebPは合計約5.8MBです。利用時の画像生成や外部の画像配信サービスは不要です。隣の絵が混ざらないように表示範囲を定義し、縦横比を保って印刷します。

## 使い方

1. 文字の種類を「ひらがなのみ」「カタカナのみ」「まぜて」から選びます。
2. 分野と1ページの組数を選びます。初期値は4組です。
3. 「出題することばを選ぶ」を開くと絵と名前を確認できます。使わないことばはチェックを外します。
4. 共通設定で作成枚数と用紙の向きを調整します。
5. 印刷プレビューを確認してカラーで印刷します。

「まぜて」はひらがなの語とカタカナの語を同じページに出します。一つの語の中では文字種を混ぜません。長音符「ー」はどちらの表記にも含みます。

長いことばは枠に収まる大きさに調整します。文字を大きくしたい場合は2〜3組を選んでください。1枚の途中では改ページしません。

## 問題データと保存

同じページで絵や名前は重複しません。複数枚では未使用の語を優先します。候補を使い切った場合は再利用します。「とけい」と「うでどけい」など答えが曖昧になる組み合わせも避けます。条件を満たす語が足りない場合は理由を表示します。

印刷と文字サイズ・用紙方向・答え表示の変更では問題を作り直しません。答えの線は問題と同じID対応から描画します。全ページを同じブラウザのlocalStorageに保持します。共有URLやJSONでの持ち出しは初期版では対象外です。

旧版からの移行では意味が一致する語の順序と除外設定を引き継ぎます。採用しなかった題材を含むページだけを同じ位置で作り直します。同音異義語は別の物へ読み替えません。例えば旧版の蜘蛛を雲に変更することはありません。

## 素材の管理

- `art-catalog.js`：240語の名前・分類・生成する対象の説明
- `art-generation.json`：組み込み画像生成ツールに渡した共通指示と出力ファイル名
- `art-manifest.json`と`art-manifest.js`：画像サイズ・保存先・元画像ハッシュ
- `assets/illustrations/*.webp`：アプリが使用する20枚のカラー素材
- `vocabulary.js`：各語の表示範囲と同時出題を避ける組み合わせ
- `legacy-ids.js`：意味が一致する旧IDから新IDへの対応表

元のPNGを保ったままFFmpegでWebPへ変換しています。画素の描き直しや自動的な物体認識による切り抜きは行いません。画像生成の出力を取り込む場合は素材IDと元ファイルのパスをJSONにして `node scripts/import-matching-art.mjs <JSONのパス>` を実行します。現在の教材では旧OpenMoji取得スクリプトは画像を取得しません。

詳しい出典は[ATTRIBUTION.md](ATTRIBUTION.md)を参照してください。

## 検証

```powershell
node --test apps/picture-word-matching/tests/*.test.js apps/custom-calculation-problem-builder/tests/*.test.js apps/dot-copy-print/tests/*.test.js apps/shared/tests/print-performance.test.js
```

専用のChrome・Edgeセッションで次のスクリプトを `playwright-cli run-code --filename <パス>` で実行します。

- `scripts/verify-picture-word-matching.js`：文字種・分野・組数・枚数・保存・除外・A4/B5/Letter PDF
- `scripts/verify-picture-word-matching-boundaries.js`：候補不足・30枚・A4横6組・390px幅・入口との往復
- `scripts/verify-picture-word-matching-print.js`：Ctrl+P・画像読み込み失敗・破損した保存データ
- `scripts/verify-picture-word-art-migration.js`：旧ID・同音異義語・ページ位置・表示範囲・旧素材の排除
- `scripts/review-picture-word-art.js`：アプリ内の実際の表示範囲で240種類を一覧化

ローカルサーバーのポートは4192です。検証用ブラウザは確認後に閉じます。実機プリンターと児童による利用は未確認です。
