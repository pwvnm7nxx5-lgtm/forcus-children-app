# 絵とことばのマッチング作成

上段の絵と下段のことばを点から点へ線で結ぶ印刷教材です。ブラウザで描く機能はありません。

## 使い方

1. 文字の種類を「ひらがなのみ」「カタカナのみ」「まぜて」から選びます。
2. 分野と1ページの組数を選びます。初期値は4組です。
3. 必要に応じて「出題することばを選ぶ」を開いて絵と名前を確認します。使わないことばはチェックを外します。
4. 共通設定で作成枚数と用紙の向きを調整します。
5. 印刷プレビューを確認してカラーで印刷します。

「まぜて」はひらがなの語とカタカナの語を同じページに出します。一つの語の中では文字種を混ぜません。長音符「ー」はどちらの表記にも含みます。

## 問題データ

425種類のカラーSVGと日本語の語彙を同梱しています。動物・食べ物・生活用品・道具・乗り物と街・自然・遊びと音楽の分野から選べます。分野内には珍しい物の名前や長いことばも含みます。児童の実態に合わせて語彙一覧で選択してください。

同じページで絵や名前は重複しません。複数枚では未使用の語を優先して選びます。候補を使い切った場合は再利用します。各ページ内で答えのことばの順序を入れ替えます。条件を満たす語が足りない場合は理由を表示して印刷を止めます。

印刷と文字サイズ・用紙方向・答え表示の変更では問題を作り直しません。答えの線は問題と同じID対応から描画します。生成済みの全ページは同じブラウザのlocalStorageに保持します。共有URLやJSONでの持ち出しは初期版では対象外です。

カラー素材はOpenMojiを採用しています。端末の絵文字フォントは使用しません。素材の出典と利用条件は[ATTRIBUTION.md](ATTRIBUTION.md)を参照してください。

## 開発と検証

ビルド不要の静的HTML/CSS/JavaScriptです。HTTPサーバーでリポジトリを開いて確認します。

```powershell
node --test apps/picture-word-matching/tests/*.test.js
```

`vocabulary.js`に語彙と画像IDを定義します。生成ロジックは`generator.js`に分離し、UIと印刷を`app.js`で扱います。共通の`apps/shared/print-adjustments.js`を変更せずに利用します。素材更新時は出典のコミットとライセンスも確認してください。

## 2026年11月4日の確認結果

- カラー素材の全件一覧を目視しました。絵と合わない名前を修正し、不明瞭な候補を除きました。
- 新規7件と計算問題作成・点つなぎ・共通印刷の回帰テストを合わせて53件が成功しました。
- ChromeとEdgeで3種類の文字設定と7分野を確認しました。2・3・4・6組と1・2・3枚の表示、再読み込みによる復元、語彙の除外、候補不足からの復旧を確認しました。
- 30枚＋答え30枚で180種類の語を重複なく配置できました。
- A4縦・A4横・B5・LetterのPDFでページ数と見切れを確認しました。答えを外すと3枚になり、付けると6枚になりました。答えの線は対応する絵と語の点に一致します。
- 390px幅での操作と入口の学年・教材フィルターからの往復を確認しました。
- 実機プリンターでの紙への出力と児童による使いやすさは未確認です。入口には「開発中」として登録しています。

ブラウザでの主要な再検証には専用セッションで `playwright-cli run-code --filename scripts/verify-picture-word-matching.js` を実行します。検証用ブラウザは終了後に閉じます。

境界条件には`verify-picture-word-matching-boundaries.js`と`verify-picture-word-matching-print.js`を使います。後者はOSの印刷ダイアログを代替関数に差し替え、Ctrl+Pから同じ印刷処理に到達することと候補不足・画像読み込み失敗時に印刷へ進まないことを確認します。これらのローカルサーバーのポートは4192です。
