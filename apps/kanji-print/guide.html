漢字なぞりプリントの使い方

文章を入力し、見本にする文字と空欄にする文字を決めて、授業に合わせたなぞりプリントを作ります。

  2. Bで濃い見本にする

  5. 空白と改行を決める

  7. 句点後の余りマスを使う
  8. テンプレートを使う

  10. 共有URLを作る

基本

まず1枚を作る

文章と設定を変えると、右側のプレビュー（画面の幅が狭いときは下側）にすぐ反映されます。次の順で作ると、初めてでも迷いにくいです。

  1. 「文章」に練習したい文を入力します。

    改行も入力できます。例えば、次のような文です。

    例大陸を横断する。 紙の中央、九州へたびに出る。 早起きする。

  2. 「文章」の設定で、空欄にする文字や空白・改行の扱いを決めます。

    見本を残したい文ならそのまま、書かせたい文字があるなら「漢字を自動で空欄にする」などを使います。

  3. 「用紙・文字」で列、行、文字の見え方を整えます。

    縦方向の1列に入れるマス数、横に並べる列数、文字サイズ、薄さなどを調整します。

  4. プレビューを確認し、「印刷 / PDF保存」を押します。

    名前と日付も必要なら先に入力します。作成する枚数を増やすと、同じ内容のプリントを複数枚作れます。

最初は初期値のまま1文だけで試し、マスの詰まり方を確認してから列・行や文字サイズを調整すると便利です。

見本の濃さ

Bで一部だけ濃い見本にする

文章の一部だけを、なぞる薄い文字ではなく、濃い見本文字にしたいときに使います。

  1. 「文章」の入力欄で、濃くしたい文字をドラッグして選択します。
  2. 入力欄の下にある B ボタンを押します。
  3. プレビューで、選択した範囲が濃い見本になったことを確認します。

入力欄の例'大陸'を横断する。→プレビュー大陸を横断する。

Bを押すと、選択範囲が半角アポストロフィ（'）で囲まれます。アポストロフィ自体はプレビューのマスには表示されません。空欄化の設定も同時に使う場合は、濃くした文字が空欄にならないかプレビューで確認してください。

空欄の作り方

漢字を空欄にする

漢字を見本にせず、児童に書かせたいときの設定です。

  1. 「漢字を自動で空欄にする」にチェックを入れます。
  2. すべての漢字を空欄にするなら、「対象漢字（空欄ですべて）」は空のままにします。
  3. 一部の漢字だけなら、「対象漢字（空欄ですべて）」に対象の漢字を入力します。例えば 山川 と入力すると、山と川が対象です。
  4. プレビューで、意図した漢字だけが空欄になっているか確認します。

文章大きな山。

すべて空欄□きな□。

対象に「山」大きな□。

「対象漢字」に入力できるのは「漢字を自動で空欄にする」をオンにしたときです。チェックを外すと、対象漢字の入力を残したままでも通常の見本に戻ります。

空欄の作り方

漢字以外を空欄にする

漢字と数字を見本として残し、かなや句読点などを空欄にしたいときに使います。

  1. 「漢字以外を自動で空欄にする」にチェックを入れます。
  2. プレビューで、漢字は見本として残り、ひらがな・カタカナ・句読点・記号などが空欄になったことを確認します。

例大きな山。3→大□□山□3

数字は空欄にならず、文字として残ります。例えば 3 や 2026 を残したまま、かなだけを練習用の空欄にできます。

漢字も空欄にしたい場合は、「漢字を自動で空欄にする」もオンにします。その場合も数字は空欄になりません。

文章の並び

空白と改行を決める

文章欄の空白や改行を、マスの並びにどう反映するかを決めます。

空白を1マス空ける

  1. 「空白を1マス空ける」にチェックを入れます。
  2. 文章中の半角スペース、全角スペース、タブが、それぞれ1つの空欄マスになります。

例山　川→山□川

空白を詰める

  1. 「空白を詰める」にチェックを入れます。
  2. 文章中の半角スペース、全角スペース、タブを取り除き、文字を続けて配置します。

例山　川→山川

改行で次の列

  1. オンにすると、改行した位置までを空欄で埋め、次の文を次の列から始めます。
  2. オフにすると、改行を取り除いて文章を続けます。

例春。 夏。→オンなら「春。」の列の次に「夏。」

「空白を1マス空ける」と「空白を詰める」は同時には使いません。片方をオンにすると、もう片方はオフになります。「漢字以外を自動で空欄にする」がオンのときは、空白も漢字以外として空欄マスになります。

用紙・文字

用紙と文字を整える

「用紙・文字」では、プリントの大きさ、向き、文字の見え方を調整します。名前と日付はプリントの上部に表示されます。

用紙の設定

列
縦方向のマスの並びを、横に何列置くか。
行
1列に何マス置くか。
作成する枚数
同じ内容のプリントを何枚作るか。
穴あけガイド
なし、左の真ん中 ◀、上の真ん中 ▲から選ぶ。
流し方向
最初の列を左から置くか、右から置くか。

文字の設定

文字サイズ
通常の文字の大きさ。
小さい文字
「ゃ」「ゅ」「ょ」「っ」などの大きさ。
句読点サイズ
「。」「、」などの大きさ。
フォント
教科書体、ゴシック、明朝から選ぶ。
文字の太さ
細い、普通、太いから選ぶ。
余白
マスの中の文字の間隔を微調整する。
文字の薄さ
なぞる文字を薄く、または濃くする。

設定例7列・12行・右から・教科書体・薄め→縦書きの列を少なめにして、右側の列から練習するレイアウト

文字が小さく感じるときは、まず列や行を少なくしてマスを広げます。列・行を増やすと1枚に入る文字数は増えますが、マスは小さくなります。

余りマスの活用

句点後の余りマスを練習に使う

短い文の下に残るマスを、その文に出てきた漢字の追加練習に使えます。

  1. 「句点後の余りマスを練習に使う」にチェックを入れます。
  2. 「下に残すマス」に、最後まで空欄で残すマス数を入力します。例えば 2 なら、列の下2マスは追加練習に使いません。
  3. プレビューで、文の後に漢字が追加され、指定した下のマスが空欄で残っていることを確認します。

例山川を歩く。→「山」「川」など、その列に見えている漢字を出てきた順で追加練習

「。」「．」「.」「！」「!」「？」「?」の後で働きます。余りが「下に残すマス」以下なら、追加できる漢字はありません。空欄になった漢字やBで濃い見本にした文字は、追加練習の候補になりません。

繰り返し使う

テンプレートを保存・適用・削除する

同じマス数や文字設定を何度も使うときは、テンプレートに保存します。

  1. 文章欄、空欄、用紙・文字、練習などを整え、「保存名」に名前を入力します。例：7列12行・右から
  2. 「保存」を押します。同じ名前がすでにある場合は、その設定で更新されます。
  3. 後で使うときは「呼び出し」から名前を選び、「適用」を押します。
  4. 不要になったテンプレートは「呼び出し」から選び、「削除」を押して確認します。

テンプレートは保存したブラウザ内に保存されます。文章、名前、日付は保存対象ではありません。列・行、枚数、穴あけガイド、文字、空欄、空白、改行、余りマス、流し方向、読み仮名表示とその時点の読み一覧などの設定を保存します。別の文章に適用した場合は、読み仮名を作り直してください。

読み仮名

読み仮名を作り、確認・修正する

読み仮名機能は現在のアプリで使えます。自動作成後に先生が確認し、単語ごとの読み方や表示方法を直せます。

  1. 「読み仮名を付ける」にチェックを入れます。

    読み仮名の操作欄が開きます。

  2. 「読み仮名を作る」を押します。

    本文から漢字を含む単語の読みを作ります。準備中は進み具合が表示され、終わると読みの一覧が表示されます。

  3. 一覧で、単語・読み・表示方法を確認します。

    各行には単語、読み欄、分ける・まとめるボタンが表示されます。黄色の 要確認 が付いた行は、読みや分け方を特に確認します。

  4. 必要な箇所を修正します。

    読み欄をクリックして入力します。入力した読みはひらがなに整えられます。読み仮名が付いたプレビューの漢字マスをクリックして、その読み欄を開くこともできます。

「分ける」と「まとめる」

分ける大陸 → 大「たい」・陸「りく」

まとめる大陸 → 「たいりく」

「分ける」を選ぶと、字ごとの読み欄が現れます。字ごとに読みを確認・修正してください。「まとめる」を選ぶと、単語全体をひとまとまりの読みとして表示します。自動判定の結果が授業の意図と違うときは、ボタンで表示方法を選び直します。

「要確認」が付いたとき

  1. 黄色の行で、単語の読み欄を確認します。
  2. 必要なら読みを修正し、「分ける」または「まとめる」を選びます。
  3. 「分ける」で字ごとの欄が空いている場合は、各欄に読みを入力します。
  4. プレビューの読み仮名が、教材として適切になったか確認します。

本文を変えたとき

本文を変更すると、一覧の上に「本文を変更しました。読み仮名を作り直してください。」と表示されます。文章を確定した後、もう一度「読み仮名を作る」を押してください。古い一覧をそのまま印刷しないよう、プレビューも確認します。

修正を保存する・消去する

  • 読みや分け方を修正すると、このブラウザに保存されます。同じ表面の単語が同じ元の読みで再び出たとき、保存した修正が自動作成に使われます。
  • 保存された行には 修正済み が付きます。保存はこのブラウザ内だけで行われ、外部へ送信されません。
  • 学習した読みを消去 は、ブラウザに保存した先生の修正を消します。現在表示中の一覧はその場では変わらないため、消去後に「読み仮名を作る」を押して結果を作り直します。

読み仮名の見え方を調整する

読み仮名の操作欄にある「サイズ」「薄さ」「余白」で、印刷する読み仮名の大きさ、濃さ、字間を調整します。

キーボードで確認する場合

読み欄で Alt+↓ または F2 を押すと、同じ行の「分ける・まとめる」に移動します。← → で選び、Enter または Space で決定、Escape で読み欄に戻ります。通常の Tab では、読み欄と字ごとの入力欄を順に移動できます。

共有

共有URLを作る

  1. 文章、空欄、読み仮名、用紙・文字などを完成させます。
  2. 「共有URLをコピー」を押します。
  3. コピーされたURLを、同じ内容を使う先生に渡します。URLを開くと、文章と設定が読み込まれます。

個人情報に注意：共有URLには文章、名前、日付、読み仮名、各設定が含まれます。児童名や個人情報を入力したまま、不特定多数が見られる場所へ公開しないでください。

コピーが許可されない環境では、アプリがURL欄に共有用データを入れます。その場合は、アドレス欄のURL全体を手動でコピーしてください。

出力

印刷・PDF保存をする

  1. プレビューで、空欄、読み仮名、名前・日付、ページ数を確認します。
  2. 「印刷 / PDF保存」を押します。
  3. ブラウザの印刷画面で、紙のプリンターを選ぶか、「PDFとして保存」などのPDF保存を選びます。
  4. 必要に応じて保存先やファイル名を決めて保存します。

プリントはA4縦向きのレイアウトです。画面上のプレビューが縮小表示されていても、印刷時は印刷用の大きさで出力されます。

読み仮名を付けた場合は、印刷画面を開く前にプレビューで読みの誤りや「要確認」の残りを確認してください。

確認ポイント

よくある困りごと

漢字が全部空欄になった

「漢字を自動で空欄にする」がオンで、「対象漢字（空欄ですべて）」が空になっていないか確認します。一部だけにしたいときは対象漢字を入力し、見本に戻したいときはチェックを外します。

漢字以外が空欄にならない・数字がどうなるか分からない

「漢字以外を自動で空欄にする」を確認します。この設定では、かな・句読点・記号などは空欄になりますが、数字は文字として残ります。数字も空欄にしたい場合は、文章の数字を削除するなど、入力文を調整してください。

空白や改行の位置が思った通りにならない

「空白を1マス空ける」と「空白を詰める」のどちらがオンか、また「改行で次の列」がオンかを確認します。空白を残したいときは前者、取り除きたいときは後者を選びます。

Bを押しても濃くならない

先に文章欄で文字を選択してから B を押します。入力欄で選択範囲が半角アポストロフィで囲まれているか、プレビューで確認してください。

読み仮名が出ない、または古い読みのままになる

「読み仮名を付ける」をオンにし、「読み仮名を作る」を押します。本文を変更した後は、一覧に本文変更の案内が出るので、もう一度読み仮名を作り直してください。

黄色の「要確認」が消えない

その行の読みを確認し、「分ける」で字ごとの読みを入力するか、「まとめる」で単語全体の読みとして表示します。入力後はプレビューの読み仮名も確認してください。

保存した読みの修正を消したい

「学習した読みを消去」を押します。今表示されている一覧はそのままなので、続けて「読み仮名を作る」を押して、自動作成し直してください。

「対象漢字」に入力できない

「漢字を自動で空欄にする」がオフだと入力欄は無効です。先にチェックを入れてください。

テンプレートが見つからない

テンプレートは保存したブラウザ内にだけあります。別のブラウザや別の端末で開いていないか、ブラウザの保存データを消していないかを確認します。

共有URLをコピーできない

コピーが使えない環境では、共有用データがアドレス欄に入ります。URL全体を選択して手動でコピーします。
